## 使用说明

- 按阶段顺序推进，同阶段内无依赖任务可并行

## 可并行说明

在满足依赖的前提下，以下任务可并行：

- **A02 / A03**：A01 完成后可并行
- **B08 / B09**：前置满足后可与 B04～B06 并行
- **C06 / C09**：可与 C01～C05 穿插进行
- **D03 / D04**：可在阶段 D 前半段并行
